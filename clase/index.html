🔗 Obj 6 — Fetch básico y JSON

Meta: pedir datos a una API con fetch y mostrar el primer usuario.

  1. Declara const URL = "https://jsonplaceholder.typicode.com/users";
  2. Crea la función async cargarUsuario():
    1. const response = await fetch(URL);
    2. Si !response.ok lanza throw new Error("HTTP " + response.status).
    3. const datos = await response.json(); → ¡el JSON ya es un array de objetos!
  3. Muestra en #resultado el nombre y correo del primer usuario: datos[0].name — datos[0].email (template literal).
  4. 📦 JSON: agrega console.log(JSON.stringify(datos[0], null, 2)) para ver el JSON crudo del primer usuario.
  5. Escucha el click del botón y llama a cargarUsuario().
  6. Cuando termines, pulsa Comprobar mi ejercicio para verificar si está bien.
👀 F12 → pestaña Console y Network: verás la petición y el JSON. El check simula la API para no depender de internet, pero tu clic usa la API real.
